# Screensaver: Time edition

A Windows screensaver: a 3D flying digital clock (WinForms + WebView2 +
Three.js) that bounces around the screen DVD-logo style, with a hidden
author signature in the corners.

- [`pre-built/`](pre-built/readme.md) - raw source code, build instructions.
- [`after-built/`](after-built/install.md) - ready-to-install build,
  installation instructions.
